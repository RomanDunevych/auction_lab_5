# Онлайн-аукціон — лабораторна робота №5 (захищена адмін-панель)

Express.js + Sequelize (SQLite) + Nunjucks + Passport.js.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # автоматичні тести
```

Якщо до цього була база з попередньої лабораторної — видаліть `database.sqlite`, щоб створилися
користувачі з реальними паролями:

```bash
rm -f database.sqlite
```

## Ролі

| Роль | Хто це | Що може |
|------|--------|---------|
| Відвідувач | неавторизований | переглядати лоти й категорії, реєструватися, входити |
| Користувач | `user` | + створювати лоти, робити ставки, змінювати/видаляти свої лоти й ставки, редагувати свій профіль |
| Адміністратор | `admin` | + керувати категоріями, статусами, користувачами (і ролями), історією; змінювати будь-які лоти й ставки |

## Демо-облікові записи

| Логін | Пароль | Роль |
|-------|--------|------|
| `admin` | `Admin123` | адміністратор |
| `seller1`, `ivan`, `olena` | `User1234` | користувач |

Усі права описано в одному місці — `auth/permissions.js`.

## Адмін-панель (`/admin`)

Захищена область лише для ролі `admin` (право `admin:access`). Відвідувача перенаправляє на `/login`,
звичайному користувачеві показується сторінка 403.

| Адреса | Дія |
|--------|-----|
| `GET /admin` | панель: кількість записів, останні лоти й ставки |
| `GET /admin/:resource` | список із пошуком (`q`), сортуванням (`sort`, `dir`) і сторінками (`page`) |
| `GET /admin/:resource/new`, `POST /admin/:resource` | створення |
| `GET /admin/:resource/:id/edit`, `POST /admin/:resource/:id/edit` | редагування |
| `POST /admin/:resource/:id/delete` | видалення |

`:resource` — `lots`, `categories`, `statuses`, `users`, `bids`, `history`. Кожну таблицю описано в
`admin/resources.js` (стовпці, поля форми, валідація, правила створення/зміни/видалення), а працює з цими
описами один універсальний контролер `controllers/adminController.js`. Нова таблиця додається одним описом.

Бізнес-правила: категорію й статус із лотами видалити не можна; системні статуси (`active`, `sold`) не видаляються;
адміністратор не може видалити чи понизити сам себе або єдиного адміністратора; користувача зі зв’язаними
записами видалити не можна; ставки створюються, змінюються й видаляються через сервіс ставок (ціна лота й історія
оновлюються автоматично); лот видаляється разом зі ставками та історією.

Для реального сайту задайте власний ключ сесій: `SESSION_SECRET=... npm start`.
